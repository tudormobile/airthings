# Sample Projects

This folder contains sample applications that utilize Airthings packages.

## Current Layout

- `SimpleConsoleApp/`: simple demonstration using the proxy client.

> [!IMPORTANT]
> Sample applications should reference the Tudormobile Airthings libraries using ***nuget packages***, not *project references*. 

## Repository Structure Guidance

`samples/` is for sample applications only. All projects in this folder should reference Tudormobile.Airthings.* libraries using published nuget packages.

- `samples/` for sample applications
- `docs/` for docs content and generated site assets.
- `src/` for source code.
